Jellyfin to Jellyfin

Mirrors remote Jellyfin libraries as .strm/.nfo/artwork and streams playback through this server. The remote password never leaves the server: generated .strm files only contain this server's stream endpoint.

General

Each instance writes into <base>/JellyfinToJellyfin/<instance id>/ unless the instance sets its own output folder.
Leave empty to auto-detect. Set it explicitly if clients must reach this server on a fixed address.
0 disables the scheduled task. Trigger changes apply after a server restart.
